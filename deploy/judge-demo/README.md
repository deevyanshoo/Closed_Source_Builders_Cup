# Hosted company, news, procurement operator and voice demo

The company selector exposes ten fictional, dated operating profiles with distinct sectors, currencies, inventory units/volumes, suppliers, orders and trade routes. Larger profiles include broader catalogues: Atlas Petrochem 12 materials, GridSpring Batteries 10 and StoneBridge Materials 8. These are demonstration records, not customer data. Solara Cables alone has runnable reviewed copper quote coverage; other profiles support company/news exploration and clearly disclose unavailable procurement coverage.

Company switching saves/restores isolated temporary workspaces. Every new browser mutation carries the expected company context version; in-flight quote/news work is rejected after a switch. Refresh and ambiguous switch failures recover the authoritative session. Public news is observed metadata, independently labelled from synthetic company operations. EIA energy headlines, ECB publications/reference rates and GDELT discovery use fixed HTTPS endpoints, a shared 15-minute process cache and a bounded parallel refresh. Unavailable/stale sources remain explicit, and no synthetic news replaces an outage. Article bodies are not republished. Headline matches indicate conditional exposure, never a confirmed shipment delay or predicted price movement.

Run `python deploy/judge-demo/company_news_smoke.py --url https://SERVICE --output /path/to/receipt.json --live --with-baseline-smoke` as the deployment owner after a release. This checks all ten profiles, context/session isolation, live source provenance and differing company relevance, plus the existing live Gemini procurement smoke when requested. A cached source receipt proves a dated observation, not a new fetch; check the receipt's observation status and source times.

The isolated `procure.demo.app` serves React `/demo` and same-origin session API. It does not change the private-machine Go gateway. Documents and economics are labelled synthetic, with optional live Vertex Gemini extraction and document-field evidence. The planner compares single-offer feasibility/cost under entered assumptions, not market timing, real procurement or a multi-period/global optimizer.

After a baseline comparison, `/api/demo/recovery` compares hypothetical supplier delays against the same reviewed quotes and buyer inputs. Original and changed arrivals, feasibility, selection and Decimal cost difference are paired in the browser and export. Empty recovery restores the original baseline, including any original delay assumptions; changed keys are absolute replacements. A delay does not change document evidence or establish a real shipment event or production impact.

`/api/demo/rfq` prepares a deterministic unsent draft only after explicit review of the current selected plan and exact offer versions. Original extracted prices and evidence stay separate from reviewer corrections, current reviewed prices and scenario totals. Drafts cannot be generated without a selected purchase. New comparisons, quote changes, extraction, reset and expiry invalidate stale draft access. The owned text download and JSON export contain the current draft; no supplier send or order endpoint exists. All state remains temporary.

Runtime is one Cloud Run instance, one Uvicorn process, max 8 concurrent requests; ephemeral sessions last one hour. Instance restart clears state and requires a fresh session. Global/per-session call and request bounds, exact fixture hashes, body limits, CSRF, origin, ownership, version and idempotency gates protect the public demo. Only synthetic bundled documents can be selected/uploaded; keys/tokens never enter client code. Repeated immutable extracted documents may be cached, explicitly labelled in browser and export.

Docker build requires reviewed production assets at apps/web/dist. Package only Python source, these deployment files, materials/assumptions YAML and the static ISO country lookup CSV, the synthetic demo documents, and reviewed web assets. Never include credentials, local virtual environments, data/raw, forecast/evaluation/work artifacts, logs or Git databases.

Cloud runtime uses `closed-source-demo@closed-source-builder-261007.iam.gserviceaccount.com`, granted the existing custom role with only aiplatform.endpoints.predict and serviceusage.services.use. Vertex project closed-source-builder-261007, location global. Set GOOGLE_GENAI_USE_VERTEXAI=true, GOOGLE_CLOUD_PROJECT, GOOGLE_CLOUD_LOCATION, RUN_LIVE_GEMINI=1, MAX_LIVE_CALLS=60 and OFFLINE=0. Cloud Run public invocation is limited to this new synthetic service; previous services and project roles remain unchanged.

Local checks use credential-free demo tests; live provider tests are separate coordinator-owned diagnostics. Deployment is complete only after cloud revision/URL and actual fresh-browser quote correction/save/plan/export are observed. Public repo publication and competition submission are separate actions.

The Operator workspace uses Gemini 3.5 Flash-Lite for a coordinator and two parallel evidence/procurement specialists, followed by a deterministic verifier. It inspects synthetic inventory attention, conditionally explains cited current news, and prepares watch, supplier-delay recovery or unsent RFQ proposals. Applying a proposal is a separate reviewed action bound to the session, company, current plan/offer versions and five-minute expiry. Older overlapping turns cannot replace a newer proposal. No email, purchase, order or supplier-send capability exists.

Google Cloud Speech-to-Text and Text-to-Speech use the existing runtime identity through server-side ADC. Push to talk is explicit, short (20 seconds/500 KB), and transcription fills editable text without automatically sending it. Spoken answers use bounded MP3 output with Stop/native playback controls. Raw audio is transient. Typed input is available when voice is unavailable. Operator limits are six turns per session, three model calls per turn and 60 per process; voice limits are eight calls per session and 40 per process. State and budgets reset on instance restart, and no durable/background monitoring is implemented.

It uses current Atlas-matched source evidence for inspection/explanation/watch and speech, then returns to Solara for procurement. Real three-role receipts, reviewed effects, replay/context/session guards, Google STT/TTS and MP3 structure are checked. Browser playback and microphone capture require separate browser verification. Synthetic WAV recognition is not proof of a human microphone walkthrough.
